# Test topshirig'i: "Frontend dasturchi (React)" lavozimi uchun

Test topshirig'i doirasida **MAX** messenjerida xabar yuborish va qabul qilish uchun foydalanuvchi interfeysini ishlab chiqish talab qilinadi.

> Agar MAX messenjeri uchun topshiriqni bajara olmasangiz, **WhatsApp** yoki **Telegram** uchun qilishingiz mumkin.

**Topshiriqni bajarish muddati:** 5 kun

---

## Talablar

1. MAX'da xabar yuborish va qabul qilish uchun foydalanuvchi interfeysini ishlab chiqish.
2. **GREEN-API** xizmatidan foydalanish: https://green-api.com/max
3. Faqat **matnli** xabarlarni yuborish va qabul qilishni amalga oshirish.
4. Interfeys prototipi sifatida chatning tashqi ko'rinishini olish: https://web.max.ru/
5. Interfeysni imkon qadar **sodda** va **minimal funksiyalar to'plami** bilan qilish.
6. Xabar yuborishni quyidagi metod orqali amalga oshirish:
   https://green-api.com/v3/docs/api/sending/SendMessage/
7. Xabar qabul qilishni quyidagi metod orqali amalga oshirish:
   https://green-api.com/v3/docs/api/receiving/technology-http-api/
8. **React** texnologiyasidan foydalanish.

---

## Kutilayotgan natija

- Foydalanuvchi chat saytiga kiradi va **GREEN-API** tizimidagi o'z akkaunt ma'lumotlarini kiritadi (`idInstance`, `apiTokenInstance`).
- Foydalanuvchi qabul qiluvchining telefon raqamini kiritadi va yangi chat yaratadi.
- Foydalanuvchi matnli xabar yozadi va uni MAX'dagi qabul qiluvchiga yuboradi.
- Qabul qiluvchi MAX messenjerida xabarga javob beradi.
- Foydalanuvchi qabul qiluvchining javobini chatda ko'radi.

---

## Natija (topshirish)

Topshiriq natijasini **hr@green-api.com** manziliga quyidagi formatda yuboring:

**Mavzu (Subject):** Test topshirig'i lavozimi uchun — Frontend dasturchi React

Xat tarkibi:

1. Rezyume — pdf fayl sifatida biriktiring (bog'lanish uchun telegram'ingizni ko'rsating).
2. GitHub repozitoriy havolasi.
3. Loyihani lokal ishga tushirish bo'yicha yo'riqnoma havolasi.
4. Internetdagi xizmat (deploy) havolasi (ixtiyoriy).
5. Skrinshotlar / video-taqdimot havolasi (agar mavjud bo'lsa).

Shuningdek, o'zingiz uchun qulay ish formatini ko'rsating: **masofaviy / Ximki ofisi / Astana ofisi**.
