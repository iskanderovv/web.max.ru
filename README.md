# Telegram Chat на GREEN-API

Тестовое задание «Фронтенд разработчик React»: веб-интерфейс чата для отправки и получения текстовых сообщений через [GREEN-API](https://green-api.com/telegram).

> **Почему Telegram, а не MAX.** Задание разрешает сделать интерфейс для WhatsApp или Telegram, если нет возможности использовать MAX. У MAX-аккаунтов GREEN-API метод `checkAccount` поддерживает только номера РФ и Беларуси, поэтому для разработки из Узбекистана выбран Telegram. Внешний вид повторяет Telegram Web. Мессенджер-специфичный код сосредоточен в `src/api/`, остальной интерфейс от него не зависит.

## Возможности

Основной сценарий из задания:

1. Вход по данным инстанса GREEN-API (`idInstance`, `apiTokenInstance`).
2. Создание чата по номеру телефона получателя (форма «New Contact»: имя, фамилия, номер).
3. Отправка текстового сообщения (`SendMessage`).
4. Получение ответа (`ReceiveNotification` + `DeleteNotification`) и отображение в чате.

Дополнительно:

- Поиск по чатам, контактам, группам, каналам и ботам; точный `@username` ищется через `checkAccount`.
- Список контактов и статус **online / last seen** (из `getContactInfo`).
- Статусы доставки: ✓ отправлено, ✓✓ прочитано (из `getChatHistory`).
- Редактирование и удаление своих сообщений (`editMessage`, `deleteMessage`), удаление чата и очистка истории.
- Индикатор «печатает» для собеседника (`sendTyping`), аватарки, подгрузка последних сообщений при открытии чата.
- Адаптивная вёрстка (на телефоне список и чат переключаются).

## Подготовка инстанса GREEN-API

1. Зарегистрируйтесь на [green-api.com](https://green-api.com) и создайте инстанс **Telegram** (тариф Developer, бесплатный).
2. Авторизуйте инстанс: в консоли откройте QR-код, в Telegram на телефоне выберите *Настройки → Устройства → Подключить устройство* и отсканируйте код. Статус должен стать `Authorized`.
3. Включите входящие уведомления: в консоли инстанса *Изменить → «Получать уведомления о входящих сообщениях»* или вызовите `SetSettings` с `{"incomingWebhook": "yes"}`. Поле `webhookUrl` должно быть пустым. Без этого ответы не попадут в очередь, и приложение покажет красное предупреждение.
4. Скопируйте `apiUrl`, `idInstance`, `apiTokenInstance` из консоли.

## Как пользоваться

1. Откройте приложение и введите `idInstance` и `apiTokenInstance` (`apiUrl` подставляется автоматически из `idInstance`, при необходимости его можно изменить).
2. Нажмите ✎ (или ☰ → New chat), введите имя и номер получателя в международном формате.
3. Напишите сообщение. Enter отправляет, Shift+Enter переносит строку.
4. Попросите получателя ответить из Telegram. Ответ появится в чате в течение нескольких секунд.

## Как это устроено

```
src/
  api/        fetch-клиент, 4 основных метода GREEN-API и вспомогательные, Zod-схемы
  store/      auth.ts, chats.ts: Zustand + localStorage
  hooks/      useNotificationPoller, useSendMessage, useChatSync, usePresence, ...
  lib/        poller.ts (receive → handle → delete), поиск, правила сообщений, время
  features/   auth/ (вход), chat/ (список, окно чата, диалоги)
```

Ключевые решения:

- **Получение сообщений.** Цикл `receiveNotification` (long-poll 20 с) → обработка → `deleteNotification`. Уведомление удаляется даже при ошибке обработки, иначе очередь FIFO встанет. При сетевых ошибках пауза растёт экспоненциально (1 → 30 с). Дубли отсекаются по `idMessage`.
- **Только открытые чаты.** Инстанс привязан к реальному аккаунту, поэтому в интерфейс попадают только сообщения из чатов, которые пользователь сам открыл. Остальные уведомления удаляются из очереди и не отображаются.
- **Оптимистичная отправка.** Сообщение сразу появляется со статусом «отправляется», затем ✓ или ❗ с повтором по клику.
- **Валидация ответов API.** Все ответы проходят через Zod, неожиданная форма даёт понятную ошибку.
- **CORS.** `api.green-api.com` отвечает `access-control-allow-origin: *`, поэтому запросы идут напрямую из браузера, бэкенд не нужен.

## Ограничения

- Статус **online** приблизителен: API не присылает события присутствия, только `lastSeen` (0, если скрыто настройками приватности).
- Индикатор «собеседник печатает» не показывается: GREEN-API такие события не отправляет.
- Поиск по всему Telegram невозможен: `getChats` возвращает только диалоги аккаунта. Пользователя или бота можно найти по точному `@username`.
- Только текстовые сообщения (по условию задания).
- Тариф Developer ограничивает число чатов и проверок существования аккаунта.

## Безопасность

`apiTokenInstance` хранится только в `localStorage` браузера пользователя и отправляется только на хост GREEN-API. В репозиторий токены не попадают. В production-версии токен следует хранить на сервере, здесь это сознательно упрощено условиями задания (чисто клиентское приложение).
